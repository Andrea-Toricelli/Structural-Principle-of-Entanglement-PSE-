The Structural Principle of Entanglement (PSE) is a theoretical framework in which distance and structural correlation 
emerge from a prespatial structure.
The ontological chain describes the formation of fundamental and emergent structures and the crossing of complexity thresholds
that make the compressive 
and non‑invertible projection maps Φ definable, from which the observable physical domain arises. 

Repository Content
This repository contains the official documentation of the PSE:

PSE – Conceptual Framework

PSE – Mathematical Formalization

Both documents define the prespatial domain, the emergence of structural correlation, 
the ontological chain, and the role of complexity thresholds in enabling the projection maps Φ that generate the physical domain.

Purpose
The repository provides a stable, versioned reference for the PSE, complementary to the Zenodo release and intended for researchers interested in theoretical physics, pregeometry, emergence, and correlation‑based foundations of physical observables.
